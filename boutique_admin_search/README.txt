Projet New-Tech Boutique

Ce projet est une boutique en ligne simple en HTML, CSS, PHP et MySQL.

Installation rapide :
1. Mettre le dossier du projet dans htdocs si vous utilisez XAMPP.
2. Demarrer Apache et MySQL.
3. Ouvrir phpMyAdmin.
4. Importer le fichier database.sql.
5. Ouvrir le site avec localhost.
